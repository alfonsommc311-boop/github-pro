🎧 Cómo usarla: estudia cada área en orden, toca Escuchar lección completa y repasa con audio. Cada lección trae ejemplos con tus propios proyectos (una app formativa, un servidor MCP, un sitio web), errores que cuestan horas y un quiz. Practica los comandos en la Terminal de esta app antes de tocar un repositorio real.
🧭 Orden recomendado: fundamentos → primer repositorio → ramas → remotos → pull requests → issues y projects → Actions → publicar → Git avanzado → seguridad → Claude Code, Copilot y CLI → casos y examen.
🛠️ Herramientas: terminal Git simulada con retos, buscador de comandos, generador de .gitignore, constructor de workflow de Actions, SOS Git (qué hacer cuando algo salió mal), checklists, plantillas y glosario.
⚠️ Esta app es formativa. Los repositorios y personas de los ejemplos son ficticios. La interfaz web de GitHub, sus planes y sus límites cambian: ante la duda, verifica en la documentación oficial (docs.github.com). Esta app no se conecta a GitHub, no llama a ninguna API y no guarda claves.
