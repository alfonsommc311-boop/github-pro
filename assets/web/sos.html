SOS Git: algo salió mal

🆘 SOS Git

Algo salió mal y no sabes qué hacer. Primero: no ejecutes nada con --force ni --hard hasta leer esto. Elige el síntoma y sigue los pasos en orden. Casi nada se pierde en Git; lo que se pierde es la calma.
Antes de cualquier remedio: git status para saber dónde estás y git reflog para tener a mano los hashes recientes. Si el repositorio es compartido, avisa antes de reescribir historia. Verifica los comandos en la documentación de Git y en docs.github.com.
