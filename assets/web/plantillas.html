✍️ Plantillas listas para copiar

README, descripción de pull request, formulario de issue, mensaje de commit, notas de release, CODEOWNERS, CLAUDE.md y más, rellenados con la ficha del proyecto. Lo que falte aparece como COMPLETAR para que nada salga a medias.

Elige la plantilla

Las plantillas son un punto de partida: adapta cada sección a tu proyecto y borra lo que no aplique. Los formatos que GitHub reconoce (plantillas de issue, CODEOWNERS, workflows) pueden cambiar: verifica en docs.github.com.
