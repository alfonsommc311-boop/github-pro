⌨️ Terminal Git simulada

Practica los comandos de Git sin riesgo: aquí no hay repositorio real ni internet. El simulador entiende un subconjunto de Git (repos, stage, commits, ramas, merge, remotos, push y pull, stash, tags, reset y revert) y cada reto verifica el estado real del repositorio simulado, no el texto que escribes. Escribe help para ver los comandos.

Retos guiados

Elige un reto: las tareas se marcan solas cuando el estado del repositorio las cumple. El botón ↺ reinicia el simulador.

Terminal

El simulador es didáctico: no reproduce todos los mensajes ni todos los casos de Git real (por ejemplo, los conflictos se resuelven automáticamente y push/pull no hablan con ningún servidor). Cuando pases a un repositorio real, verifica cada comando en la documentación de Git y en docs.github.com.
